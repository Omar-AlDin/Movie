# 🎬 Movie Guessing Game

An interactive, web-based movie guessing game built with pure vanilla JavaScript, HTML5, and CSS3. 

🔗 **Live Demo:** [Play the Game Here](https://omar-aldin.github.io/Movie/)

---

## 🚀 Features

* **Dynamic Game Logic:** DOM manipulation for handling user input, score tracking, and game-state updates.
* **Skip & Hint Mechanics:** Built-in skipping system and visual hints to keep gameplay engaging.
* **Responsive UI:** Clean CSS styling with custom media assets, adaptive borders, and dynamic feedback states.
* **Zero Dependencies:** Built entirely with plain JavaScript without relying on external frameworks or libraries.

---

## 🛠️ Tech Stack

* **Language:** JavaScript (ES6+)
* **Structure:** HTML5
* **Styling:** CSS3
* **Hosting:** GitHub Pages

---

## 🕹️ How to Play

1. Open the [Live Demo](https://omar-aldin.github.io/Movie/).
2. Look at the visual/text clues for the movie.
3. Type your answer and check if you got it right!
4. Use skips or hints if you get stuck, and try to score as high as possible.
